Bölüm 1 · İmpor masterının 16 sorusu

Товар и контракт — «что приехало и по какому договору»

Вопрос мастераПочему важноДанные в системеСейчас
С1 По какому ПИ и какой категории пришёл этот груз? Договор заключается по категории поставщика. Без пары (ПИ, категория) остаток не считается. CI Item.custom_proforma_invoice + .category строка есть, свода нет
С2 Сколько ещё осталось по этому контракту? Заказано 10 конт. — 3 пришли, 7 в пути? Это решение о следующей отгрузке. ПИ строки − CI строки по ключу только в отчёте
С3 Цена совпадает с договорной? Один ключ может нести несколько контрактных цен; отклонение = переплата. rate vs ПИ rate, допуск 0,005 бейдж «расходятся»
С4 Недогруз / перегруз есть? Перегруз по ключу — это чужой контракт, минус в остатке. коробки: ПИ vs CI только в отчёте
С5 Разбивка по отрубам сходится с упаковочным? Compensated — микс внутри контейнера может гулять, сумма демета нет. boxes × box_weight = qty в таблице товаров

Деньги — «сколько это стоит и кому я должен»

Вопрос мастераПочему важноДанные в системеСейчас
Д1 Себестоимость килограмма с транспортом и таможней? Цена продажи ставится отсюда. Без этого маржа считается «на глаз». Container Cost Line + Import Expense + Customs Declaration.total_duties нигде в CI
Д2 Сколько транспорт и кому? Перевозчик — отдельный поставщик; долг перед ним живёт отдельно. Import Expense (supplier, invoice_reference, purchase_invoice) нет
Д3 Аванс 70% оплачен по каждому контейнеру? Без оплаты нет телекс-релиза → контейнер стоит и капает демередж. Import Container.payment_70_status/_amount/_date только внутри контейнера
Д4 Банк / нал — как разложилось? Документальная и договорная цена разные; разница идёт налом. docs_price vs rate, bank/cash_payment суммы есть, разреза нет
Д5 Пошлины и НДС по ГТД? Часть себестоимости и повод для сверки с декларантом. Customs Declaration.duty/vat/excise/total_duties не видно в CI

Логистика и время — «где груз и что горит»

Вопрос мастераПочему важноДанные в системеСейчас
Л1 Где сейчас каждый контейнер? 10 статусов от BOOKED до DELIVERED_TO_UZBEKISTAN. Import Container.status в списке контейнеров
Л2 Опаздываем? Демередж капает? Разница ETA vs факт и gate_in → таможня. Каждый день = деньги. etd/eta, gate_in_date, customs_clearance_date, cut_off даты есть, счётчика нет
Л3 Телекс-релиз / BL получен? Без него контейнер не выдают. bl_type, telex_release_date внутри контейнера

Документы и приёмка — «можно ли растаможить и принять»

Вопрос мастераПочему важноДанные в системеСейчас
Б1 Вет-сертификат есть и не просрочен? Мясо без действующего вета не проходит границу. Vet Certificate.status/expiry_date отдельная страница
Б2 ГТД подана / выпущена? Статус растаможки = когда можно забирать. Customs Declaration.status/cleared_date отдельная страница
Б3 Склад принял? Расхождение есть? Недостача = претензия поставщику, порог 2/5/10%. GRN Checklist.variance_*/claim_required блок готовности
